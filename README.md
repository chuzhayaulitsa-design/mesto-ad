# Mesto. Валидация форм и сборка кода

Проектная работа спринта «Сборка кода и модульность. Валидация форм»: сервис Mesto — приложение, в котором можно добавлять и удалять фотографии, ставить лайки, редактировать профиль и аватар.

## Что сделано

- К проекту подключён сборщик Vite (`npm run dev` — запуск dev-сервера с автоматическим открытием страницы в браузере, `npm run build` — сборка проекта);
- JavaScript-код разбит на модули: `card.js`, `modal.js`, `validation.js`, `cards.js`, точка входа — `index.js`;
- Реализована кастомная валидация всех форм (редактирование профиля, добавление карточки, обновление аватара) с кастомными сообщениями об ошибках и блокировкой кнопки отправки.
